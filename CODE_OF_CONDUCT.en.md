# Code of Conduct

[![日本語](https://img.shields.io/badge/%E3%81%82-%E6%97%A5%E6%9C%AC%E8%AA%9E-5B6670?style=for-the-badge)](CODE_OF_CONDUCT.md) [![English](https://img.shields.io/badge/A-English-087F8C?style=for-the-badge)](CODE_OF_CONDUCT.en.md)

This project embraces the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).

## Our Pledge

We pledge to provide an open, harassment-free environment for all contributors and users. We respect every participant, regardless of age, body size, disability, ethnicity, gender identity or expression, level of experience, nationality, personal appearance, race, religion, sexual orientation, or identity.

## Our Standards

- Use considerate language
- Respect differing viewpoints and experiences
- Welcome constructive criticism
- Focus on what is best for the community

## Reporting Violations

If you witness a violation of this Code of Conduct, contact the repository maintainers.
