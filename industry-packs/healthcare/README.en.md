# industry-packs/healthcare/

[![日本語](https://img.shields.io/badge/%E3%81%82-%E6%97%A5%E6%9C%AC%E8%AA%9E-5B6670?style=for-the-badge)](README.md) [![English](https://img.shields.io/badge/A-English-087F8C?style=for-the-badge)](README.en.md)

This is the Industry Pack for Healthcare. Its standard scenario is Healthcare Case History Search. It uses entirely fictional data only.

Prohibited actions: automatically confirming diagnoses, automatically determining treatments, automatically recommending medications, using real patient data, and making clinical judgments without human review.

Every response must include Synthetic data notice / Not medical advice / Human clinical review required.

The implemented entities are SyntheticPatient, Provider, Encounter, and ClinicalEvent. The MCP Tools do not perform diagnosis, prescription, or treatment decisions.

For usage instructions, see the [lab portal](../../docs/index.md) or the [production environment setup guide](../../docs/Production-Environment-Setup.md).
