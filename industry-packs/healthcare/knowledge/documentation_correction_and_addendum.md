# 記録訂正・追記手順（合成参考文書）

> 文書ID: `HC-KB-005` / 版: 1.0 / 所有者: clinical documentation lead / 見直し: 半年ごと。本書は架空の記録管理例である。

## 手順

1. 訂正対象の記録ID、原記録日時、記録者、問題点を特定する。
2. 原記録を削除・上書きせず、訂正または追記として理由を記録する。
3. 事実誤り、表記修正、遅延記録を区別する。
4. 訂正者、承認者、訂正日時、参照証跡を保持する。
5. 関連する受診・イベントの表示へ反映されたことを確認する。

## 例外と承認

- 患者ID不一致、作成者不明、臨床的意味が変わる訂正はclinicianへエスカレーションする。
- エージェントは原記録を変更せず、診断や治療内容を補完しない。
