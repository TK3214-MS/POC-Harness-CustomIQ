# industry-packs/public-sector/

[![日本語](https://img.shields.io/badge/%E3%81%82-%E6%97%A5%E6%9C%AC%E8%AA%9E-087F8C?style=for-the-badge)](README.md) [![English](https://img.shields.io/badge/A-English-5B6670?style=for-the-badge)](README.en.md)

Public Sector向けIndustry Packです。標準シナリオはPublic Sector Case Investigationです。

禁止事項: 給付または許認可の自動決定、行政処分の自動化、市民のリスクランキング、保護属性に基づく判断。

実装済みentityはSyntheticCitizen、Agency、Case、Applicationです。`manifest.yaml`は`IndustryPackManifest`で検証されます。

利用方法は[ラボポータル](../../docs/index.md)または[本番環境構築ガイド](../../docs/Production-Environment-Setup.md)を参照してください。
