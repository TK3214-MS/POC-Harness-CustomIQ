# Healthcare Terminology Glossary (Synthetic Demo Pack)

| Term | Definition |
|---|---|
| SyntheticPatient | A fully synthetic patient. Not a real person. |
| Provider | A synthetic healthcare provider role. |
| Encounter | A synthetic clinical encounter between a SyntheticPatient and a Provider. |
| ClinicalEvent | A synthetic event recorded during an Encounter (e.g. vital_signs_recorded, lab_test_ordered). |
| age_band | A synthetic age range (e.g. "40-49"), never a real patient's exact age. |
