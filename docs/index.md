# Industry IQ Platform Labs

Microsoft Fabric IQ、Foundry IQ、Work IQをCopilot Studioへ接続し、業界別の業務質問を検証するハンズオンラボです。

## ラボ構成

| トラック | 対象 | 所要時間 | ゴール |
| --- | --- | ---: | --- |
| 合成データE2E | ソリューションアーキテクト、Copilot Studio作成者 | 3〜4時間 | 5業界から1つを選び、3つのIQレイヤーを接続して検証する |
| 実顧客Ontology設計 | ソリューションアーキテクト、データ設計担当者 | 別途計画 | metadataと匿名化sampleから、承認可能なOntology設計成果物を作る |
| MCP Backend | 上級者、連携実装担当者 | 任意 | 顧客固有Business System向けToolの接続方法を確認する |

[ラボを開始する](labs/index.md){ .md-button .md-button--primary }
[開始前チェックを開く](labs/prerequisites.md){ .md-button }

!!! warning "開始前に確認"
    このラボは受講者ごとの既存tenantを使用します。必要なライセンス、Preview提供状況、tenant設定、capacity、ロールが確認できない場合は、構築を開始せず管理者へ確認してください。Microsoft製品の提供条件は実施日時点の公式文書で再確認します。
