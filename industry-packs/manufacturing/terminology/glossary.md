# Manufacturing Terminology Glossary (Synthetic Demo Pack)

| Term | Definition |
|---|---|
| Factory | A synthetic manufacturing plant. |
| ProductionLine | A production line operated within a Factory. |
| Supplier | A synthetic supplier of Parts. |
| Part | A component sourced from a Supplier and used in one or more ProductionLines. |
| QualityIssue | A detected quality problem affecting a Part, observed at a Factory. |
| EngineeringChange (EC) | A proposed/approved/implemented change to address a QualityIssue's root cause. |
| defect_rate_percent | Synthetic defect rate for a QualityIssue, expressed as a percentage. |
| reliability_score | Synthetic 0.70-0.99 score representing a Supplier's historical reliability. |
