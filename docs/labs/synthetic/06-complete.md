# Lab 6: 完了確認

想定時間: 20分

## 結果を記録

| 項目 | 必須証跡 |
| --- | --- |
| Local | contract test、synthetic validation |
| Fabric IQ | Instances、1-hop Graph、refresh日時 |
| Foundry IQ | indexer成功、文書名、引用付き回答 |
| Work IQ | 配置先、閲覧権限、対象record ID |
| Copilot Studio | `F-01`、`F-02`、`K-01`、`W-01`、`X-01`、`X-02`の結果 |
| Activity trace | 実際のTool、結果、エラー、必要時のCorrelation ID |

各質問は`Pass`、`Partial`、`Fail`で記録します。評価基準は[テスト質問集](../../evaluation/Copilot-Studio-IQ-Layer-Test-Catalog.md)の「評価基準」を使用します。

## 完了条件

- [ ] 必須の単一レイヤー質問がすべて`Pass`である。
- [ ] `X-01`と`X-02`が`Pass`または理由を記録した`Partial`である。
- [ ] 資格情報を含まない証跡を保存した。
- [ ] 残課題にownerと次の確認日を設定した。
- [ ] ラボresourceを保持するか削除するか承認者と決めた。

Azure上の任意MCP Backendを試す場合は[上級ラボ](../advanced-mcp.md)へ進みます。追加の回帰試験には[全50問のテスト質問集](../../evaluation/Copilot-Studio-IQ-Layer-Test-Catalog.md)を使用します。
