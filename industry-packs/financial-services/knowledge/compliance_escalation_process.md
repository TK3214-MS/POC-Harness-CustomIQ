# Compliance Escalation Process (Synthetic Reference Document)

> This is a synthetic reference document created for the Industry IQ Platform Accelerator demo. It does not represent a real institution's process and cites no real regulations.

## Escalation Path

1. A fraud analyst investigates the case and documents findings.
2. If confirmed fraud is suspected, the case is escalated to a compliance officer.
3. The compliance officer decides on account-level actions (e.g., temporary hold) - never an automated system.

## Human Approval Requirement

See `industry-packs/financial-services/manifest.yaml` `human_approval_rules` - freezing an account or closing a fraud case always requires a named human approver role.
