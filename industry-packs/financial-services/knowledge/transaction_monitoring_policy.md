# Transaction Monitoring Policy (Synthetic Reference Document)

> This is a synthetic reference document created for the Industry IQ Platform Accelerator demo. It does not represent a real institution's policy and cites no real regulations.

## Monitoring Thresholds

- A transaction amount more than **3x** an account's average transaction amount is flagged for review (synthetic threshold for demo purposes).
- Multiple flagged transactions on the same account within a short period increase the case's `risk_score`.

## What This Policy Does Not Do

This policy does not authorize automated account freezes, automated transaction reversals, or automated credit decisions. All such actions require human review by a fraud analyst or compliance officer.
