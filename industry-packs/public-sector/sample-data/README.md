# Public Sector sample data

All records are synthetic. Upload `fabric/cases.csv` to Fabric Lakehouse and load it as a managed table for the `Case` entity type. Use `work-iq/` as optional content in a dedicated test workplace account.

The existing `knowledge/` documents are the optional Foundry IQ document set.

Enterprise assets: `fabric/enterprise/` contains generator-produced CSV tables, `foundry/enterprise/records.jsonl` contains knowledge records, and `prompts/enterprise_prompts.yaml` contains 50 prompts across five scenarios.
