# industry-packs/financial-services/

[![日本語](https://img.shields.io/badge/%E3%81%82-%E6%97%A5%E6%9C%AC%E8%AA%9E-5B6670?style=for-the-badge)](README.md) [![English](https://img.shields.io/badge/A-English-087F8C?style=for-the-badge)](README.en.md)

This is the Industry Pack for Financial Services. Its standard scenario is Financial Fraud Investigation.

Prohibited actions: automatic account freezing, automatic transaction rejection, automatic legal judgments, and automated assessment of an individual's creditworthiness.

The implemented entities are Customer, Account, Transaction, and FraudCase. `manifest.yaml` is validated with `IndustryPackManifest`.

For usage instructions, see the [lab portal](../../docs/index.md) or the [production environment setup guide](../../docs/Production-Environment-Setup.md).
