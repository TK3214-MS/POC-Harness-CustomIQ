# ADR-0001: リポジトリルート = アクセラレータルート

- ステータス: Accepted
- 日付: 2026-09-08

## コンテキスト

指示書のリポジトリ構成案は `industry-iq-platform/` というルートフォルダを想定している。しかし実際のワークスペースは既に git リポジトリのルートであり、`LICENSE` 等が直下に存在する。

## 決定

ワークスペースルート（このリポジトリの直下）をそのままアクセラレータのルートとして扱う。`industry-iq-platform/` という二重ネストのフォルダは作成しない。

## 影響

- 以降のすべてのパス参照はリポジトリルート相対で記述する。
- 将来、このアクセラレータを別リポジトリへ切り出す、または複数アクセラレータを1つのモノレポにまとめる場合は、本 ADR を見直す。
