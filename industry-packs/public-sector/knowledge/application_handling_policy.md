# Application Handling Policy (Synthetic Reference Document)

> This is a synthetic reference document created for the Industry IQ Platform Accelerator demo. It does not represent a real agency's policy.

## Application Statuses

- `submitted`: awaiting initial review.
- `in_review`: a case officer is actively reviewing.
- `approved` / `denied`: a final administrative decision - always made by a case officer, never automated.
- `pending_more_info`: additional information requested from the citizen.

## Fairness Note

Decisions must never be based on a protected attribute, and this accelerator never ranks citizens by risk.
